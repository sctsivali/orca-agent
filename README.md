# ORCA Agent

Public downloads for ORCA Agent, the cluster-side worker for OrcaHub Expose Services.
Download published artifacts from [Releases](https://github.com/sctsivali/orca-agent/releases).

This repository contains distribution documentation and release assets. Source code,
build scripts, tests, signing automation, and gateway tooling are maintained privately.

## Installation and Updates

Use the instructions generated by your OrcaHub organization under Network → Expose
Services. They select the supported version and architecture and configure the agent
service for your organization and cluster. Keep registration credentials private.

## Release Assets

Asset availability depends on the release. Signed releases provide:

- `orca-agent-linux-x86_64.tar.gz` and `orca-agent-linux-aarch64.tar.gz`: self-contained
  Linux binaries for the corresponding architecture.
- `orca-agent.pyz`: a Python zipapp for supported hosts.
- `orca_agent-<version>-py3-none-any.whl`: the Python package.
- `SHA256SUMS`, `SHA256SUMS.sig`, and `signing-key.asc`: checksums, their detached
  signature, and the public signing key.

Follow the compatibility requirements in the selected release and its installer.
Existing release tags and assets are immutable.

## Verify Downloads

The approved primary signing-key fingerprint is:

```text
318F8AFC31888F13AE9F68BC2F6F8C318AD69032
```

Compare the key and actual signature signer with that independently approved
fingerprint. A key downloaded alongside an artifact does not establish its identity.

From the directory containing the downloaded assets:

```bash
gpg --show-keys --with-fingerprint signing-key.asc
gpg --import signing-key.asc
gpg --status-fd 1 --verify SHA256SUMS.sig SHA256SUMS
sha256sum -c SHA256SUMS
```

Proceed only when signature verification succeeds, its primary signer matches the
approved fingerprint, and every listed checksum passes.
